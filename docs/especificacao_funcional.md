# Especificação funcional do painel legislativo

Versão exploratória: 9/10/2026. Público: pessoas sem conhecimento prévio do processo legislativo. Recorte inicial: 57ª legislatura (2023–2027), com filtro histórico apenas para indicadores cuja fonte e cobertura forem verificadas. Câmara e Senado mantêm identificadores, regras e séries separados. O painel nunca soma parlamentares ou projetos de Casas diferentes sem deixar a composição explícita.

**Estados da matriz:** `viável na amostra` significa apenas que os campos necessários foram observados; `a validar` exige semântica, cobertura ou ligação adicional; `bloqueado` impede publicação da métrica até encontrar fonte adequada. Um valor vazio da API não é zero observado. Toda métrica publicada mostrará fonte, período, data de atualização, definição, filtros aplicados e proporção de registros sem dado.

## Regras de comparação e estados de interface

- Unidade de contagem: projeto = `(casa, id_projeto)`; votação = `(casa, id_votacao)`; pessoa = `(casa, id_parlamentar)`. A identidade de uma pessoa entre Casas e o vínculo de um projeto remetido dependem de identificador explícito, não de nomes, número ou ementa semelhantes.
- Em toda série, o filtro temporal significa **data do evento medido**: apresentação para iniciativas, realização para votações/sessões, publicação para normas e data de referência para composição. O período histórico disponível pode diferir por métrica.
- Estados exibidos: `0 observado` (consulta válida e completa sem ocorrências), `sem registros na amostra` (consulta exploratória limitada), `cobertura incompleta`, `fonte indisponível`, `ainda não validado` e `erro de atualização`. Não transformar respostas vazias isoladas em zero histórico.
- Percentuais só aparecem com numerador, denominador, critérios de elegibilidade e cobertura verificáveis. Filtros que eliminem toda a amostra exibem `Nenhum registro para os filtros selecionados`.
